# FlixPrice Privacy Policy / 隐私政策 Effective date / 生效日期：2026-10-09 ## Purpose / 用途 FlixPrice compares public Netflix subscription prices and converts them into a selected currency. It is an independent extension, not affiliated with Netflix. FlixPrice 比较 Netflix 公开套餐价格并换算货币，为独立扩展。 ## Local data / 本地数据 The extension stores selected regions, favorites, language, currency, fee preferences, automatic-update preferences, collected prices, source links, verification times, price-change history, exchange rates, errors and collection progress in chrome.storage.local. This information is not sent to the developer. CSV exports are saved locally when requested by the user. 所选地区、收藏、语言、货币、手续费、自动更新设置、价格、来源、核验时间、价格变化历史、汇率、错误和采集进度保存在 chrome.storage.local，不发送给开发者。CSV 由用户主动导出到本地。 ## Network requests / 网络请求 The extension requests public regional pages from https://help.netflix.com and public exchange rates from https://open.er-api.com. The requested Netflix URL identifies a region. These providers receive normal connection metadata such as IP address, requested URL and request time, and handle that data under their own policies. Extension data requests omit account cookies. FlixPrice does not request Netflix account credentials or access viewing history, payment information or arbitrary browsing history. 扩展访问 Netflix 官方帮助中心和 ExchangeRate-API；Netflix 请求地址含地区代码。服务方会收到 IP 地址、请求地址和时间等通常网络信息，并按各自政策处理。扩展的数据请求不携带账号 Cookie，不要求 Netflix 密码，不访问观看历史、支付信息或任意网页浏览历史。 ## Developer collection and sharing / 开发者收集与共享 FlixPrice has no developer-operated collection server, analytics, advertising or tracking. The developer does not collect, sell or transfer the extension’s local records. No remote executable code is loaded. Links opened by the user are handled by the destination website and browser. FlixPrice 没有开发者运营的数据收集服务器、统计、广告或追踪；开发者不收集、出售或转交扩展本地记录。不加载远程可执行代码。用户主动打开链接后，目标网站和浏览器按各自规则处理访问。 ## Control and deletion / 控制与删除 You can change collection settings, disable automatic updates, stop collection, or remove the extension. Local extension storage can be removed through the browser’s extension/site-data management. Previously exported CSV files remain until you delete them separately. 可修改采集设置、关闭自动更新、停止采集或卸载扩展；本地扩展数据可通过浏览器扩展和网站数据管理删除。已导出的 CSV 文件需单独删除。 ## Contact / 联系 For privacy questions, contact the publisher through the FlixPrice Chrome Web Store listing’s support channel once the listing is available. Before publication this document is a prepared policy, and no public listing is claimed to exist. 隐私问题可在上架后通过 FlixPrice 的 Chrome 应用商店支持渠道联系发布者。上架前本文为已准备的政策，不代表商店页面已存在。 ## Changes / 更新 Future changes to data handling will be reflected in this policy and the extension’s store disclosures before release. 后续数据处理变化会在发布前同步更新本政策和商店披露。
